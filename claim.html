Step 3

Pay by name

Calls payByName. The contract forwards exactly the amount you send. A name that does not exist reverts, so a mistyped name cannot send funds to the wrong place.

Step 4

Escrow by name

Calls escrowByName. Funds lock for 7 days. The name owner releases them with confirmDelivery. The payer can refund any time before confirmation, and anyone can trigger the refund after the deadline. The escrow id comes back in the transaction receipt.

How the payment works

An Agent ID name is a token on the SPACE ID Agent ID contract. Its token id is the keccak256 hash of the lowercase label. NamedPay reads the owner of that token id on chain, then routes the payment. Four functions carry the product.

FunctionWhat it doesCost
registerPayeeName owner claims the name as payable, or changes its payout address1 tx, about $0.002 gas
payByNameForwards exactly the amount sent to the payout address1 tx, no fee
escrowByNameLocks funds for the named agent for 7 days1 tx, no fee
confirmDelivery / refundReleases escrowed funds to the agent, or returns them to the payer1 tx each

Gas figures are mainnet estimates at 0.05 gwei, the live gas price measured Nov 18. Testnet gas is paid in free testnet BNB. There is no fee on payments in version 1.

What the contract can and cannot do

  • The deployer can pause new registrations, payments, and escrows in an emergency. The deployer can never move user funds. There is no fee switch, no upgrade path, and no withdrawal function.
  • A pause never blocks fund release. Confirm delivery, refund, and timeout refund keep working while paused.
  • NamedPay is not a wallet lookup tool. There is no lookup on this page, and the payout address appears only as the confirmation line of a payment the visitor started.
  • Labels are case insensitive, and one trailing .ai is stripped, so Alice, alice, and alice.ai all resolve to the same name.

The hackathon

NamedPay is built for the Binance Agent ID Hackathon, Innovation track. The prize pool is 60,000 USDC across the Growth and Innovation tracks. The Innovation jury scores Agent ID application depth at 30 percent, practicality and feasibility at 25 percent, product completeness at 25 percent, and innovation at 20 percent. Eligibility needs 30 distinct Agent ID holder addresses interacting with the submitted contract between Nov 18 and Dec 9, 2026. Submissions close Dec 9, 2026 at 09:00 WAT.

The entry is a contender at 30 plus real interactions with the complete package. It becomes the favorite only if two things land: a live agent to agent payment by name, verifiable on BscScan, and 100 plus real interactions. Neither has landed yet. The mainnet deploy is the next step, and the interaction drive starts the day it goes live.
